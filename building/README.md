# Building

RevOS skills for building software. One folder per skill, named `revos-<skill>`, each with a `SKILL.md`. Skills that only work as a set sit together in a pack folder.

| Pack | Skills | What it does |
|---|---|---|
| [revos-replica](revos-replica/) | eleven `revos-replica-*` skills, from recon to deploy | Rebuilds what an existing app does (features and flows, clean-room style), tests it, fixes what its users hate, then rebrands it and ships it as your own. Run order, tools and credits are in its [README](revos-replica/README.md). |

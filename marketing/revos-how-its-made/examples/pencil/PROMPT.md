# How a pencil is made: build prompt

Look: `STYLE.md` sections 3 and 4. Kit: HyperFrames + Three.js (`assets/shots.js`).

## The one idea

There is no lead in a pencil: it is graphite and clay baked into stone, sandwiched in
cedar, and "lead" is a 450-year-old wrong guess.

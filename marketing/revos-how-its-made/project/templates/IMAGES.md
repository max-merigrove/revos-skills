# {{TITLE}}: pictures and clips

Everything the 3D cannot or should not draw. Real people, places, events and products are
real photographs from a source that allows reuse (public domain, Wikimedia Commons with
the licence noted, the manufacturer's press kit); never generated. Generated pictures are
only for generic objects and analogies.

Files go in `assets/images/`; each is used in `reel.json` `plates`.

## Prompt style for generated plates

Append to every image prompt:

> Photoreal 3D product render, single object centred, floating on a near-black warm studio
> background (#0c0b0a), warm key light from the top left, faint cool rim light from behind,
> soft contact shadow, shallow depth of field, vertical 9:16, 1080x1920, no text, no logos,
> no people.

For a clip (image to video), start from that still and ask for one slow move only (a 5 %
push in, or the object turning 15 degrees), 3 to 5 s, no cuts.

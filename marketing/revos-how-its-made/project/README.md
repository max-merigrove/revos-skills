# merigrove-how-its-made

Narrated "how it's made" explainer reels (1080 x 1920, 30 fps) in the look of
speedy_devv's tyre and hydrogen-bomb reels: a dark product studio in 3D, one step
per sentence, captions with a blue keyword box, callouts that track the parts.
The look is broken down in `STYLE.md`. The process is the skill `revos-how-its-made`.

Rendering is HyperFrames (HTML to video). The 3D is Three.js, bundled locally in
`kit/three.bundle.js`, drawn only from timeline time so any frame renders the same.

```

kit/

templates/               PROMPT.md, IMAGES.md, shots.js and reel.json to start a reel from
scripts/
  new-reel.mjs           node scripts/new-reel.mjs "How a pencil is made"  -> reels/<date>_<Slug>/
  build-reel.mjs         node scripts/build-reel.mjs reels/<dir>  (re-run after every change)
  voice.mjs              text: script.txt -> TTS parts (pronounce applied); join: parts -> assets/vo.wav
  check-vowel.py         did the voice say "led" or "leed"? (lead, read)
  vendor.mjs             rebuilds kit/three.bundle.js
  doctor.mjs             npm run doctor: every requirement, then a real 3D test frame
  setup.mjs              makes a project from the copy packed in the skill (new machines)

  script.txt             the voiceover script

  reel.json              shots, word marks, callouts, stats, plates, caption highlights
  assets/shots.js        the 3D for each shot (HM.shot)
  assets/vo.wav          the voiceover; assets/transcript.json its word times

```

## First time on a machine

The skill `revos-how-its-made` has the full set-up checklist. In short: Node 22, ffmpeg 8+,
`npx hyperframes@0.9.9 doctor` green for Chrome and whisper, Python with numpy and scipy,
the hyperframes skills, then `npm install && npm run vendor && npm run doctor`.

## Make a reel

```bash
node scripts/new-reel.mjs "How a pencil is made"
# write script.txt, PROMPT.md, IMAGES.md (the skill does this), get approval
# record or generate the voice to reels/<dir>/assets/vo.wav, then:
cd reels/<dir>
npx hyperframes transcribe assets/vo.wav --model small.en
node ../../scripts/build-reel.mjs .
npx hyperframes check
npx hyperframes snapshot --at 2,6,10      # look at every shot
npx hyperframes render -o Output/<name>.mp4 -f 30 -q high --browser-gpu
```

## Time is words

Nothing in a reel is timed in seconds by hand. `reel.json` names the spoken word
where each shot cuts in, where each callout and stat appears, and where each move
inside a shot starts (`marks`). A new take of the voice re-times the whole film.

An "at" is a word (`"graphite"`), its nth time after the search start
(`"lead#2"`), a word with an offset (`"lead-0.05"`, `"baked+0.3"`), alternatives
(`"1000|thousand"`: Whisper writes numbers as digits on one take and words on the
next), or seconds (`12.4`). Shots search forward from the previous shot; everything inside a shot
searches forward from the shot's first word. A short word like "a" or "the" will
match the first one it finds: anchor on a word that only occurs where you mean.

## reel.json

| Key | Meaning |
| --- | --- |
| `title`, `voice`, `transcript`, `music {src, volume}`, `sfx [{src, at, volume}]` | The film and its sound |
| `tail`, `fadeIn`, `fadeOut` | Seconds after the last word; fades to black |
| `look {exposure, vignette, grain}`, `bloom {strength, radius, threshold}` | The grade, for every shot |
| `shots[]` | In order: `id` (matches `HM.shot`), `at`, `in` (`cut` or `dissolve`), `inDur`, `marks {name: at}` |
| `shots[].callouts[]` | `text`, `anchor` (a name in the shot's `anchors` or a named object), `at`, `until`, `lead` (px), `angle` (deg, 0 is straight up), `down` (label below the leader end) |
| `shots[].stats[]` | `num` (a number counts up from `from`; a string shows as is), `unit`, `suffix`, `decimals`, `anchor` or `x`/`y` (px), `at`, `until`, `lead`, `angle` |
| `plates[]` | Pictures over the 3D: `kind` (`print` a photo on a desk with `name`; `full` a still with a slow push; `float` an object on the dark studio; `video` a clip), `src`, `shot`, `at`, `until`, `year`, `push` |
| `pronounce` | `{written: spoken}` respellings for the voice (`"lead": "led"`); captions map them back |
| `captions` | `highlight` (words in order, `"w"` or `{w, emoji}`), `maxWords` (5), `fix {heard: shown}` |

## The kit (window.HM)

A shot is registered in `assets/shots.js`:

```js
HM.shot("kiln", {
  set: { keyPos: [-2, 5, 3], fog: 0.06, floor: true, floorY: 0, key: 1, rim: 1, env: 0.35 },
  bloom: { strength: 0.6, threshold: 0.8 },          // optional, this shot only
  build(scene, kit, shot) { /* add meshes */ return refs },
  camera: [{ p: 0, pos: [x, y, z], look: [x, y, z], fov: 34 }, { p: 1, ... }],
  update(refs, p, local, dur, t, shot) { /* p 0..1; shot.marks.heat = seconds into the shot */ },
  anchors: { tray: (refs, v) => v.set(0, 0.1, 0) },   // world points for callouts
});
```

- Units: pick one per reel and keep it (the pencil uses 1 = 10 cm). The set's lights are
  placed for objects about 0.5 to 2 units across, 2 to 5 units from the camera.
- Maths: `HM.after(local, mark, dur, ease)` (a move that starts on a word), `HM.seg`,
  `HM.ease.{inOut,out,in,outBack,smooth}`, `HM.lerp`, `HM.clamp`, `HM.rng(seed)` (never `Math.random`).
- Materials: `HM.mat.wood({seed, base, dark})`, `paint(color)`, `graphite()`, `metal()`,
  `rubber()`, `clay()`, `matte()`, `hot()` (turn up `emissiveIntensity`), `glass()`.
- Parts: `HM.hexPrism(r, len)`, `HM.spheres(n, {radius, material})` (instanced: `place(i, x, y, z, s)` then `done()`),
  `HM.glow(color, size, opacity)`, `HM.shade(obj)` (shadows on), `HM.tex.{wood,noise,glow,canvas}`.
- Cuts with clipping planes work (`renderer.localClippingEnabled` is on): see the pencil's `shape` shot.
- Lumpy organic shapes: displace an icosahedron and run `THREE.mergeVertices` before
  `computeVertexNormals`, or it renders faceted (see `lump()` in the pencil reel).

## Traps found building the pencil

- White surfaces (paper) blow out under the key: keep them mid-grey (#7d776c reads as paper).
- Emissive heat turns white through ACES and bloom when it is bright or covers a big area:
  deep red-orange (1, 0.12 to 0.26, 0.01 to 0.04), intensity under 1, and small hot parts.
- Rows of thin rods seen side-on merge into a board: point them at the lens.
- Anything that travels toward the lens ends as a blob filling the frame: travel away from it.
- The 9:16 frame is narrow: lay long objects along the depth axis or diagonally, not across.
- Callout labels near a frame edge need an `angle` pointing inward; keep them under y 168 px clear.

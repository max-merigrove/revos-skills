# Before and after

What a founder gets from a general AI chat when they ask "why does ChatGPT never mention us?", and what they get from this skill, for the same message. Both businesses are fictional.

A general chat is good at half of this job. It writes an answer-first page, a JSON-LD block and an llms.txt, says nobody can guarantee a citation, and often spots a robots.txt that blocks a search crawler. The skill adds the half that decides whether anything changed: a test built from real buyer questions, counts over several runs, facts checked by script, and a memory for the retest.

## A financial modeller selling to start-ups in the US and Canada

| | A general chat | With this skill |
|---|---|---|
| Offer on the page | Fills in a structure she never gave: extra packages, a call length, bracketed guesses such as "[24/36] months". | Uses only what she confirmed (her two rounds, her price "from USD 4,500", two to three weeks, one tool). Nothing else can reach a page: the claims gate refuses it. |
| A test | "Re-run your target prompts in a month", with no prompts, run count or sheet. | 8 buyer questions (3 in buyers' own words), a run protocol, and a workbook that scores named, cited and recommended as "x of y, n equals y" with ranges, UNKNOWN below three runs. |
| Buyer questions | Three it made up. | Her buyers' questions, word for word, tagged heard; the rest tagged derived from her own offer words. |
| Structured data | Adds FAQ markup without saying Google retired the FAQ rich result on 7 May 2026; nothing checked. | Business, person and service markup only, parsed and checked; FAQ markup only if she asks. |
| Files | One chat reply. | The Quote Kit, the workbook, page text, JSON-LD and llms.txt, plus a memory file for the retest. |

## A web studio in Rotterdam (Dutch, messy paste)

| | A general chat | With this skill |
|---|---|---|
| Reach | Catches the search-crawler block from a security plugin and writes a corrected file. | The same finding, with the corrected file re-checked so no other crawler changes, and a note to change it in the plugin's settings. |
| Contradictions | Writes a page answer around an old review that says "3 weeks". | Asks; she says 4 to 6 weeks and 3 was an exception, so "binnen 3 weken" is declined and kept out of every file. |
| Facts | Suggests case pages naming clients, and markup with "[TELEFOON]" placeholders. | No client named without permission; no placeholder in any markup; fields left out until confirmed. |
| Prices | "€ 4.800" as she wrote it. | The same, enforced by script in every file. |
| A test | "Test after a month with questions like ..." | 8 questions in Dutch, a 54-row run sheet, a baseline before any change, and a dated retest. |
| Language | Dutch. | Dutch: the pages, the panel and the kit. |

What a general chat also does well, and the skill keeps: refusing to promise a citation, separating search crawlers from training crawlers, recommending accurate business profiles and real reviews, and saying that changes take time to be picked up.

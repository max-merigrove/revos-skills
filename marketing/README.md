# Marketing

RevOS skills for marketing. One folder per skill, named `revos-<skill>`, each with a `SKILL.md`.

| Skill | What it does |
|---|---|
| [revos-vsl-writer](revos-vsl-writer/) | Writes a VSL or call-funnel video script from a fact-gathering intake, using a 14-section flow (hook, credibility, opportunity, price-first offer, objections, fit, CTA, proof, plus a skeptic pass for long versions), then QA-checks it. |

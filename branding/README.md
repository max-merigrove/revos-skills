# Branding

RevOS skills for branding. One folder per skill, named `revos-<skill>`, each with a `SKILL.md`.

| Skill | What it does |
|---|---|
| [revos-brand-voice](revos-brand-voice/) | Builds a measured voice guide and a ready-to-paste AI voice prompt from a founder's own writing and speech, so ChatGPT, Claude, a VA or an agency writes like them. Counts every habit with a script, keeps the founder's own spelling, phrasing, money and dates, and calibrates against their ear. |
| [revos-carousel-copywriter](revos-carousel-copywriter/) | Turns any idea into slide-by-slide copy for an Instagram carousel or LinkedIn document post, plus a paste-ready Claude Design prompt. |

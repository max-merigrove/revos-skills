# Brand Consistency Scan memory

Skill: revos-brand-consistency-scan | Memory version: 1 | Updated: YYYY-MM-DD

Keep this file. Attach it next time (or leave it in your merigrove-memory folder, or your Claude Project) and the scan picks up where you left off: it scores your changed assets against the line you agreed. You can edit it by hand. It holds no client names, fees or contact details; they are removed before anything is read, and this file is checked for them before it is saved.

`scripts/check_memory.py write` builds this file from a finished scan; this template shows its shape.
